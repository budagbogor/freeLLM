❓ Tanya Jawab Populer (FAQ)

Apakah saya harus mendaftar dan mengisi semua 14 provider? ▼
Tidak perlu sama sekali! Anda cukup mendaftar ke 1 atau 2 provider saja (misal: Groq dan Gemini). Provider lain bersifat opsional sebagai cadangan. Sistem FreeLLM Hub akan langsung bekerja meskipun Anda hanya mengisi 1 provider.
Bagaimana cara kerja 1 Master API Key di Cursor / OpenCode? ▼
Di pengaturan Cursor/OpenCode, Anda cukup memasukkan Base URL: http://localhost:3000/v1 dan API Key: sk-freellm-master. Ketika Anda memilih model auto-free, server lokal akan meneruskan prompt ke provider aktif Anda. Jika satu provider terkena limit/kuota habis, server otomatis mengalihkan prompt ke provider cadangan tanpa memutuskan koneksi di IDE Anda!
Apakah data dan kunci API saya aman? ▼
100% Aman. Server ini berjalan sepenuhnya di komputer lokal Anda (localhost). Kunci API hanya disimpan di file .env lokal di komputer Anda dan langsung dikirim ke server resmi provider (seperti Google atau Groq) tanpa melalui perantara server pihak ketiga mana pun.
Bagaimana jika saya punya 2 atau 3 akun gratis di Groq atau Gemini? ▼
Anda bisa memasukkan beberapa kunci sekaligus dengan memisahkannya menggunakan tanda koma di file .env, contoh: GROQ_API_KEY=gsk_kunci1,gsk_kunci2. Server akan otomatis memutar (*round-robin*) kuncinya secara bergiliran sehingga kuota Anda berlipat ganda!
Mengapa saat mencari, kartu provider tiba-tiba hilang? ▼
Hal tersebut terjadi jika kotak pencarian terisi teks atau email otomatis dari browser. Cukup hapus teks di kotak pencarian atau klik tombol "✕" di ujung kotak pencarian untuk menampilkan kembali semua provider.
